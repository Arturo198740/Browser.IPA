UPDATING NITO TV:
==================================================

Method 1 - Within Nito TV App:
1. Launch Nito TV
2. Go to Settings/Updates
3. Refresh Sources
4. Install available updates

Method 2 - Via SSH:
ssh root@your-apple-tv-ip
apt-get update
apt-get upgrade

Method 3 - Reinstall:
ssh root@your-apple-tv-ip
curl -O http://nitosoft.com/ATV4/installNTV.sh
chmod +x installNTV.sh
./installNTV.sh

==================================================
SSL CERTIFICATE ERRORS (COMMON ISSUE):
==================================================

If you get "SSL certificate problem: unable to get local issuer certificate"

FIX 1 - Edit apt sources to use HTTP:
nano /etc/apt/sources.list.d/nito.list

Change HTTPS to HTTP:
  FROM: deb https://nitosoft.com/electra ./
  TO:   deb http://nitosoft.com/electra ./

  FROM: deb https://nito.tv/repo ./
  TO:   deb http://nito.tv/repo ./

Save (Ctrl+O, Enter, Ctrl+X) and run:
apt-get update

FIX 2 - For wget SSL errors, use curl or HTTP:
curl -O http://nitosoft.com/ATV4/installNTV.sh
OR
wget http://nitosoft.com/ATV4/installNTV.sh

FIX 3 - Try installing CA certificates:
apt-get install ca-certificates --fix-missing

==================================================
TVOS 12.1.2 SPECIFIC FIXES:
==================================================

If checkra1n doesn't work on tvOS 12.1.2:
1. Use USB-A to USB-C cable (NOT USB-C to USB-C)
2. Download latest checkra1n 0.12.4+ from releases page
3. Try ChimeraTV instead (better compatibility with 12.1.2)
4. Connect directly without USB hubs
5. Try different USB ports or computers
